# 사실 확인 메모 (판매 전에 꼭 읽기)

전자책에 들어간 사실관계를 어떻게 확인했는지 적어 둔 메모입니다. 이 작업 환경에서는 나라장터·조달청·법제처 누리집에 직접 접속할 수 없었습니다. 그래서 웹 검색 결과(공공기관 공고문, 법령 발췌, 연구 보고서)로 확인했습니다.

판매 전에 아래 **"직접 확인 권장"** 항목만이라도 원문과 대조해 주세요.

## 확인된 내용

| 원고 내용 | 근거 |
|---|---|
| 협상에 의한 계약: 정보시스템·SW 사업은 보통 기술 90 : 가격 10 | 한국개발연구원(KDI) 2025년 입찰공고 원문의 평가 기준. SPRi 보고서에서도 "기술:가격 = 9:1" |
| 기술능력 점수가 배점한도의 85% 이상이면 협상적격자, 종합점수 순으로 협상 | 같은 KDI 공고문과 협상계약 해설 자료 |
| 협상계약 공고는 제안서 제출 마감 전날부터 40일 전이 원칙. 긴급하거나 고시금액 미만이면 10일 전 | 국가계약법 시행령 제35조 제5항 조문 발췌 |
| 긴급 입찰 공고는 마감 전날부터 5일 전까지 가능(4장 본문에는 넣지 않음) | 같은 조 제4항 |
| 1인 견적 수의계약 기본 한도 2천만 원 | 2026년 7월 재정경제부 입법예고 기사("인구감소지역 기업은 2천만 원에서 5천만 원으로 상향" 추진)에서 현행 기준이 2천만 원임을 확인 |
| 청년창업기업과의 물품·용역 계약은 추정가격 5천만 원 이하 수의계약 사유 | 국가계약법 시행령 제26조 조문 발췌(법제처) |
| 복수예비가격 15개 중 4개 추첨 → 산술평균이 예정가격, 기초금액의 ±2% 또는 ±3% 범위 | 학술 논문(한국정보통신학회), 서울시 자료, 실무 해설. 기관마다 다를 수 있다는 점도 원고에 적어 둠 |
| 소프트웨어사업자(컴퓨터관련서비스사업, 업종코드 1468)를 참가자격으로 요구하는 공고 | 한국문화예술위원회 등 공공기관 제안요청서 |
| 직접생산확인은 중소기업자간 경쟁제품의 세부품명 단위, 판로지원법 근거 | 실무 해설 자료 |
| 지문보안토큰(Bio 보안토큰)으로 전자입찰 본인 확인 | 조달청 지정 제품 안내 자료 |
| 조달청 「입찰참가자격등록 매뉴얼」·「이용자등록 매뉴얼」 | 조달청 누리집 자료실(2025년 3월 게시) |
| 나라장터 콜센터 1588-0800 | 공공기관 입찰공고문의 문의처 안내 |

## 직접 확인 권장

| 항목 | 이유 | 확인할 곳 |
|---|---|---|
| 수의계약 금액 기준(2천만 원·5천만 원)과 여성·장애인기업 특례 | 개정이 잦고, 2026년 개정안(인구감소지역 기업 상향 등)의 시행 여부를 확인하지 못함 | 국가법령정보센터 → 국가계약법 시행령 제26조 |
| 지방계약법 수의계약 기준 | 원고에는 "다를 수 있다"고만 씀 | 지방계약법 시행령 제25조 |
| 소프트웨어사업자 신고 기관(한국소프트웨어산업협회) | 일반적으로 알려진 내용이지만 원문으로 재확인하지 못함 | 한국소프트웨어산업협회 누리집 |
| 중소기업확인서 발급처(중소기업현황정보시스템), 직접생산확인 신청처(공공구매종합정보망) | 위와 같음 | 각 누리집 |
| 공동인증서 유효기간 "보통 1년" | 인증서 종류에 따라 다를 수 있음 | 발급 기관 |

## 일부러 넣지 않은 내용

아래 내용은 검색으로 확인하지 못했습니다. 그래서 숫자를 쓰지 않고 "공고문에서 확인"으로 안내했습니다.

- 적격심사 낙찰하한율 수치
- 적격심사 통과 점수
- 사전규격 공개 기간
- 2인 이상 견적 수의계약 금액 구간

## 고칠 때

1. 원고 `first-bid-guide.md`를 고칩니다.
2. `python build.py --author "이름" --cta "신청 주소"`로 PDF를 다시 만듭니다.
3. 표지의 판(예: "2026년 11월판")은 원고 맨 위 `edition:` 값을 바꾸면 됩니다.
