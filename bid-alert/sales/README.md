# 판매 계획: 맞춤 입찰공고 알림 + 전자책

## 한 줄 요약

전자책 「나라장터 첫 입찰 가이드」로 잠재 고객을 모으고, 매일 아침 자동으로 나가는 **맞춤 입찰공고 알림**을 월 구독으로 판매합니다. 알림은 한 번 설정하면 GitHub Actions가 평일마다 알아서 보내므로, 운영자가 손댈 일은 신규 고객 설정과 문의 응대 정도입니다.

## 누구에게 파나

- 공공기관 납품을 하고 싶은데 **영업·입찰 전담 인력이 없는** 5~30인 회사
  - 업종 예: 홈페이지·SW 개발, 솔루션, 교육 운영, 행사 대행, 디자인, 컨설팅
- 이미 나라장터를 쓰지만 **매일 검색하느라 시간을 쓰는** 대표나 영업 담당자
- 1인 기업·프리랜서(수의계약 위주)

**수요는 확인돼 있습니다.** 크몽에 비슷한 서비스("나라장터 맞춤 입찰공고 알림해 드립니다", kmong.com/gig/798424)가 이미 올라와 있습니다. 가격과 후기를 먼저 보고 차별점을 정하세요. 우리 쪽 차별점은 다음과 같습니다.
- 마감 D-day 표시
- 정정공고 표시
- 제외어와 금액·지역 필터
- 엑셀 첨부
- AI 추천 이유

- 연간 결제는 2개월치를 할인해 주는 식으로 이탈을 줄입니다.
- 체험에 AI 추천을 넣는 이유는, 가장 눈에 띄는 기능을 먼저 보여 주기 위해서입니다.

**원가(추정):**
- 나라장터 API: 무료
- GitHub Actions: 비공개 저장소 무료 사용량 안에서 하루 1~2분
- AI: 프로 고객 1곳당 하루 100원 안팎, 월 2천 원대

AI 비용은 실제 사용량으로 측정한 값이 아니니, 첫 달 Anthropic 콘솔의 사용량을 보고 가격을 조정하세요.

**예시 계산(예측 아님):** 프로 10곳과 베이직 20곳이면 매달 약 80만 원이 들어옵니다.

## 가장 잘 먹히는 영업 방법: "지난 2주 리포트"

잠재 고객에게 "서비스가 좋습니다"라고 말하는 대신, **그 회사에 맞았을 지난 2주치 실제 공고**를 보여 주세요. 코드에 이미 그 기능이 있습니다.

```bash
# 1) subscribers.toml 에 잠재 고객을 임시로 추가 (회사 소개, 키워드)
# 2) 지난 14일 공고(이미 마감된 것 포함)로 그 회사 전용 메일을 파일로 생성
python -m bidalert run --dry-run --include-closed --only "잠재고객 회사명" --start 202610260700 --end 202611090700
# 3) out/잠재고객_회사명.html 을 PDF로 저장하거나 캡처해서 보냅니다
```

보낼 메시지 예시:

> 안녕하세요, OO님. 귀사 홈페이지를 보고 지난 2주 동안 나라장터에 올라온 공고 중 귀사에 맞는 공고를 뽑아 봤습니다. 모두 37건이었고, 이 중 3건은 아직 마감 전입니다(첨부). 이런 메일을 매일 아침 7시에 받아 보시겠어요? 2주 무료입니다.

> **주의:** 처음 연락하는 상대에게 영리 목적의 메일을 보낼 때는 정보통신망법의 광고성 정보 전송 규정을 지켜야 합니다. 제목에 "(광고)"를 붙이고 수신 거부 방법을 적어야 하며, 사전 동의 없이 보내면 안 되는 경우가 있습니다. 공개된 문의 창구로 먼저 연락해 동의를 받는 편이 안전합니다.

## 판매 채널

1. **크몽·숨고 같은 서비스 마켓:** 알림 서비스와 전자책을 각각 등록합니다. 문구는 `listing-copy.md`에 있습니다.
2. **블로그·카페:**
   - "나라장터 첫 입찰 체크리스트 무료 PDF" 글을 올리고, 이메일을 받는 사람에게 전자책을 줍니다.
   - 글 주제 예: "공고문 읽는 10가지", "1인 견적 수의계약이란"
3. **협회·지인:** 같은 업종 대표 모임에 체험판을 돌립니다. 소개로 들어온 고객이 가장 오래 남습니다.

## 신규 고객 받는 순서 (고객 1곳당 15분)

1. 회사 소개, 하는 일, 안 하는 일, 원하는 금액대, 지역 제한을 받습니다.
2. 키워드·제외어 초안을 만들고, 위의 "지난 2주 리포트"로 결과를 보여 준 뒤 조정합니다.
3. `SUBSCRIBERS_TOML` 시크릿에 고객 블록을 추가합니다.
4. 다음 날 아침 첫 메일이 잘 갔는지 확인하고, "키워드를 바꾸고 싶으면 회신 주세요"라고 안내합니다.
5. 체험 마지막 날 결제 안내를 보냅니다.
