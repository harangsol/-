# 보장분석 브리핑 PPT 제작 기획서

**문서 버전** v1.0 · **작성일** 2026-09-17 · **원본** 현장 브리핑 녹음 2건(총 35분 24초)

## 0. 분석 개요와 제약

### 0.1 분석 대상

| 구분 | 파일 | 길이 | 성격 |
| --- | --- | --- | --- |
| 파일 A | `a28a1489-____.m4a` | 23분 23초 | 현장 풀버전 — 브리핑 + 개별 Q&A + 부가서비스 안내 + 영업팀 내부 대화 |
| 파일 B | `d523dbf8-____1.m4a` | 12분 01초 | 정제된 브리핑 — 동일 콘텐츠의 압축·정리 버전, 발표자 장호준 |

두 녹음은 **같은 대본을 서로 다른 현장에서 진행한 것**이다. 3개 케이스, 5문항 자가진단, 신청서 작성 유도라는 골격이 완전히 일치한다. 따라서 PPT는 하나로 만들고, 현장 여건에 따라 분량만 조절하는 구조가 맞다.

### 0.2 전사 방법과 신뢰도

음성 인식은 Whisper large-v3(파일 B) 및 Whisper large-v3-turbo(파일 A)를 VAD 분절과 함께 CPU에서 수행했다. 전사 결과는 `transcript-A-23min.txt`, `transcript-B-12min.txt`에 타임스탬프와 함께 보관했다.

**주의할 제약이 있다.** 현장 녹음이라 다음 항목은 기계 전사만으로 확정할 수 없다. PPT에 싣기 전 반드시 원본 청취로 확인해야 한다.

| 항목 | 전사 결과 | 상태 |
| --- | --- | --- |
| 회사명 | "블리츠"(파일 B) / "굴리치"·"브리치"(파일 A) | **확인 필요** |
| 사례 인물명 | 김성호(원) 대리 / 박지원(정호) 과장 / 이장원(이원찬·정) 차장 | 가명 처리 권장 |
| 소속 분석 전문가 수 | "6,000명이 넘습니다" vs "6명" | **확인 필요 — 수치 차이가 큼** |
| 암종별 치료비 | "가낭/간암" 6,600만 · "최장암/췌장암" 6,300~6,700만 · 폐암 4,600만 | **확인 필요** |
| 케이스 1 누수액 | 996만원(파일 A·B 일치) / 월 119,000원(일치) | 신뢰 가능 |

## 1. 원본 브리핑 구조 분석

### 1.1 실제 진행 흐름

두 녹음에서 공통으로 관찰되는 흐름은 다음과 같다.

```
① 도입   자기소개 + 대리점 포지셔닝("국내 모든 보험사 취급")
② 참여   손들기 질문 — "보험 1개 이상 있는 분?" → "3개 이상?" → "5개 이상?"
③ 전환   "보험 왜 가입하세요?" → "내가 낸 보험료만큼 보장받고 있나?"
④ 본론   같은 회사 동료 3인의 실제 진단 사례
         CASE 1  중복보장   — 7년 996만원 누수
         CASE 2  세대 전환   — 4세대 갈아타기의 역효과
         CASE 3  진단비 부족 — 3,000만원으로는 모자란 암 치료비
⑤ 종합   세 사람의 공통점 = "가입할 때만 보고 중간점검을 안 했다"
⑥ 해법   무료 「내 보장 진단 성적표」 제시 + 조직 역량 소개
⑦ 행동   5문항 자가진단 체크 → 신청서 작성 → 개인정보 동의
⑧ 마무리 개별 Q&A, 부가서비스(소화기 점검), 연락 시간대 확보
```

### 1.2 화법의 핵심 자산

이 브리핑이 작동하는 이유는 세 가지다. PPT는 이 셋을 **시각적으로 강화**하는 역할을 맡는다.

- **참여로 시작한다.** 손들기 질문으로 청중을 먼저 움직이게 한 뒤 본론에 들어간다. 슬라이드는 이때 방해가 되면 안 된다.
- **숫자 하나로 기억시킨다.** 996만원, 20% 인상, 3,000만원 대 6,600만원. 각 케이스가 숫자 한 개로 압축된다.
- **청중과 같은 처지의 인물을 세운다.** "같은 회사에 다니는 세 분"이라는 설정이 거리감을 없앤다.

### 1.3 파일 A에서만 나타난 요소

파일 A 후반부에는 브리핑 본편이 아닌 내용이 섞여 있다. PPT 본편에서는 제외하되, 일부는 부록 슬라이드로 살릴 가치가 있다.

| 내용 | 위치 | PPT 반영 |
| --- | --- | --- |
| 보험료 절감 실사례 "30만원 → 22만원, 보장 동일" | 14:18 | **부록 슬라이드로 채택** |
| 숨은 보험금 찾기 서비스 | 14:18~15:06 | **부록 슬라이드로 채택** |
| 소득 대비 보험료 적정선 논의(10%는 과다) | 10:14~11:00 | **본편 자가진단 보조 설명으로 채택** |
| 소화기 무료 점검·교체 부가서비스 | 13:44~16:18 | 별도 리플릿 분리 권장 |
| 영업팀 내부 동선·리드 처리 대화 | 18:13~21:07 | 제외(내부용) |

## 2. PPT 목표와 사용 조건

### 2.1 목표

이 PPT의 목표는 단 하나다. **참석자가 자기 보험을 의심하게 만들고, 그 자리에서 무료 진단 신청서를 작성하게 하는 것.** 보험 상품을 파는 자료가 아니다.

### 2.2 사용 조건

| 항목 | 내용 |
| --- | --- |
| 장소 | 사업장 방문 브리핑(회의실·휴게공간), 화면이 작거나 없을 수 있음 |
| 청중 | 5~20명 규모 임직원, 보험 지식 편차 큼(현직 설계사 가족도 있었음) |
| 시간 | 표준 12분 / 확장 20분 — 파일 A·B의 실제 소요 시간 |
| 발표 환경 | 발표자가 목이 쉰 상태로 진행한 사례 있음 → **슬라이드만 봐도 메시지가 전달되어야 함** |
| 배포 | 화면 투사 + 인쇄 병행. 흑백 출력에서도 판독 가능해야 함 |

### 2.3 성공 지표

| 지표 | 측정 방법 | 목표 |
| --- | --- | --- |
| 신청서 작성률 | 작성 매수 ÷ 참석 인원 | 60% 이상 |
| 개인정보 동의 체크율 | 동의 체크 매수 ÷ 작성 매수 | 95% 이상 |
| 연락 가능 시간대 기재율 | 기재 매수 ÷ 작성 매수 | 90% 이상 |
| 발표 시간 준수 | 실측 | 12분 ± 2분 |

## 3. 메시지 아키텍처

전체를 관통하는 한 문장은 다음과 같다.

> **"보험은 가입할 때가 아니라, 점검할 때 완성된다."**

세 케이스는 이 문장을 세 방향에서 증명한다.

| | CASE 1 | CASE 2 | CASE 3 |
| --- | --- | --- | --- |
| 한 줄 | 7년간 996만원이 샜다 | 싸다고 갈아탄 게 더 비싸졌다 | 3,000만원으론 부족했다 |
| 손해의 성격 | 낸 돈이 헛돈 | 미래 보험료 폭증 | 정작 필요할 때 부족 |
| 원인 | 중복보장 | 세대 전환 | 물가·의료비 상승 |
| 청중 반응 유도 | "나도 여러 개 있는데" | "나도 갈아타라는 말 들었는데" | "3천이면 충분한 줄 알았는데" |
| 핵심 수치 | **996만원** | **20% vs 3%** | **3,000만원 vs 6,600만원** |

## 5. 주요 슬라이드 상세 설계

### 5.1 슬라이드 8 — 실손·비례 vs 정액보장

브리핑에서 가장 이해가 어려운 대목이다. 원본 설명은 이렇다.

> "이미 실손으로 가입이 됐는데 다른 보험에 추가적으로 같은 특약이 들어갈 수 있잖아요. 같은 걸 보장해 주는 거예요. 그럼 보험료도 나갔는데 정작 일이 발생했을 때 한 개의 돈이 지급되면 나머지는 지급이 안 되는 거죠."

시각화는 **지갑 3개 중 1개만 열리는 그림**으로 간다. 보험 3건에서 보험료는 3배로 빠져나가지만, 실제 사고 시 지급되는 것은 1건이라는 구조를 한 장에 담는다. 정액보장은 반대로 3건 모두 지급된다는 대비를 같은 레이아웃으로 나란히 놓는다.

### 5.2 슬라이드 13 — 갱신 인상률 시뮬레이션

가장 설득력이 높은 장표다. 두 개의 꺾은선을 그린다.

- 1세대 유지: 30,000원에서 연 3~5% 상승
- 4세대 전환: 15,000원에서 연 20% 상승

교차 시점을 큰 점으로 찍고, 그 지점에 "여기서부터 손해"라고 표기한다. 10년 누적 납입액 차이를 하단에 병기한다.

**주의:** 인상률은 상품·연령·연도별로 달라진다. 시뮬레이션임을 슬라이드 하단에 명시하고, 가정값(기준 보험료, 인상률, 기간)을 각주로 남긴다.

### 5.3 슬라이드 15 — 진단비 vs 치료비 격차

좌우 대칭 막대로 간다. 왼쪽은 실제 수령 평균 진단비, 오른쪽은 실제 치료비. 가운데 격차를 붉은 화살표로 연결한다.

| 암종 | 평균 수령 진단비 | 실제 치료비 | 부족액 |
| --- | --- | --- | --- |
| 간암 | 약 2,700만원 | 약 6,600만원 | 약 3,900만원 |
| 췌장암 | 약 2,600만원 | 약 6,300만원 | 약 3,700만원 |
| 폐암 | 약 2,600만원 | 약 4,600만원 | 약 2,000만원 |

**이 표의 수치는 전사 기반 추정치다. 출처 확인 전까지 PPT에 넣지 않는다.** 6장 검증 체크리스트 참조.

### 5.4 슬라이드 20 — 자가진단과 신청

원본의 5문항을 그대로 쓴다. 응답은 `그렇다 / 비슷하다 / 아니다` 3단이다.

1. 매월 납입하는 총 보험료 액수를 정확히 알고 있다
2. 중복으로 내고 있는 불필요한 보험료가 없다
3. 매월 납입 보험료가 내 소득 대비 적정하다
4. 뇌경색·협심증·표적항암치료까지 보장되는 최신 약관을 갖고 있다
5. 나에게 필요한 보장 성적표를 받아보고 싶다

하단에 신청서 기재 항목을 명시한다. **성함 / 생년월일 / 성별 / 연락처 / 상담 편한 시간대 / 개인정보 제공 동의 체크.**

그리고 원본에서 발표자가 반복해 강조한 문장을 그대로 넣는다.

> "이게 비용이 발생하는 건 아니고요. 이걸 했다고 보험을 가입하셔야 하는 이런 일은 없습니다."

## 10. 착수 전 결정 필요 사항

제작을 시작하기 전에 다음 네 가지를 확정해야 한다.

1. **회사명과 브랜드 표기** — 전사에서 "블리츠" 계열로 들리나 확정되지 않았다. 로고·컬러·정식 상호가 필요하다.
2. **분석 전문가 규모** — 6명과 6,000명은 슬라이드 설계가 완전히 달라진다.
3. **암 치료비 통계 출처** — 이 자료의 설득력이 여기 달려 있다. 공신력 있는 출처가 없으면 슬라이드 15는 재설계해야 한다.
4. **사례 3인의 실제 데이터 사용 가능 여부** — 실제 진단 결과를 쓸 수 있는지, 가공 예시로 바꿔야 하는지에 따라 CASE 슬라이드 표기가 달라진다.
