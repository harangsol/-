# 일레븐랩스 내레이션 대본

두 영상용입니다. 줄마다 영상 속 시작 시간이 정해져 있으니, **한 줄씩 따로 생성**해서 시간에 맞춰 얹는 방식을 권합니다. 대본 전체를 한 번에 생성하면 쉬는 길이가 화면과 어긋납니다.

| 영상 | 파일 | 길이 |
|---|---|---|
| 인스타 숏폼 | `out/harangsol-short-9x16-voice-ready.mp4` | 20초 |
| 정책자금 | `out/harangsol-fund-9x16-voice-ready.mp4` | 40초 |

`-voice-ready` 파일은 음성이 잘 들리도록 배경음악을 낮춘 판입니다(-21 LUFS). 음성 없이 올릴 때는 `-voice-ready`가 없는 파일을 쓰세요.

---

## 1. 일레븐랩스 설정

| 항목 | 권장 | 메모 |
|---|---|---|
| 모델 | **Eleven Multilingual v2** | 한국어 발음이 안정적입니다. 쉼은 `<break time="0.3s" />`로 넣습니다(최대 3초) |
| 대안 모델 | Eleven v3 | 감정 표현이 더 풍부합니다. `<break>` 대신 `[short pause]` 같은 오디오 태그를 씁니다 |
| 목소리 | 한국어 원어민, 30~40대, 차분하고 신뢰감 있는 상담가 톤 | 보이스 라이브러리에서 "Korean", "narration", "calm", "professional"로 검색 |
| Stability | 45~55% | 낮추면 감정이 커지지만 줄마다 톤이 달라질 수 있습니다 |
| Similarity | 75% 안팎 | |
| Style | 15~25% | 높이면 과장되게 들립니다 |
| Speed | 숏폼 **1.0** · 정책자금 **1.05** | 줄이 자리보다 길면 1.1까지 올리세요 |

- **발음 팁**: 숫자나 영어가 어색하게 읽히면 한글로 바꿔 넣습니다. 예: `12억` → `십이억`, `R&D` → `알앤디`.
- **톤 통일**: 첫 줄을 마음에 들게 뽑은 뒤 같은 목소리·설정으로 나머지 줄을 생성합니다. 시드(seed)를 고정할 수 있으면 고정하세요.

## 2. 얹는 방법

**자동 (권장)**: 줄 ID를 파일 이름으로 저장하고 명령 한 줄을 실행합니다.

```
promo-video/vo/short/S1.mp3 … S6.mp3
promo-video/vo/fund/F1.mp3 … F7.mp3

python3 tools/mix_vo.py short   → out/harangsol-short-9x16-with-voice.mp4
python3 tools/mix_vo.py fund    → out/harangsol-fund-9x16-with-voice.mp4
```

각 음성을 정해진 시간에 놓고, 음성이 나오는 동안 배경음악을 자동으로 줄이고, 전체를 -14 LUFS로 맞춥니다. 음성이 자리보다 길면 몇 배속으로 다시 만들지 알려 줍니다.

**수동 (캡컷·프리미어)**: `-voice-ready` 영상을 올리고, 아래 표의 시작 시간에 음성 클립을 하나씩 놓습니다.

## 3. 인스타 숏폼 (20초)

목소리 톤: 담담하게 묻고, 3번 줄에서 확신 있게. 광고 성우 같은 과장된 톤은 피합니다.

| ID | 시작 | 자리 | 대사 | 연출 |
|---|---|---|---|---|
| S1 | 0:00.15 | 3.4초 | 매출은 늘었는데, 왜 남는 돈은 없을까요? | 공감하듯, 물음표에서 살짝 올림 |
| S2 | 0:04.10 | 2.2초 | 상품이 아니라, 순서입니다. | "순서"에 힘 |
| S3 | 0:06.50 | 3.0초 | 매출보다 중요한 건, 돈의 흐름입니다. | 쉼표 뒤 반 박자 쉬기. "돈의 흐름"이 8초 음악 폭발과 겹치도록 |
| S4 | 0:10.10 | 3.8초 | 조달하고, 지키고, 남기고, 키우는 것까지 봅니다. | 단어마다 화면 아이콘이 하나씩 켜짐. 리듬감 있게 |
| S5 | 0:14.05 | 3.8초 | 지금 상황만 알려주세요. 순서부터 정리해 드립니다. | 따뜻하게, 권유 |
| S6 | 0:17.95 | 2.0초 | 프로필 링크로 신청하세요. | 또박또박 |

**한 번에 붙여 넣기용 (Multilingual v2)**

```
매출은 늘었는데, 왜 남는 돈은 없을까요? <break time="0.6s" />
상품이 아니라, 순서입니다. <break time="0.4s" />
매출보다 중요한 건, <break time="0.5s" /> 돈의 흐름입니다. <break time="0.6s" />
조달하고, 지키고, 남기고, 키우는 것까지 봅니다. <break time="0.4s" />
지금 상황만 알려주세요. 순서부터 정리해 드립니다. <break time="0.3s" />
프로필 링크로 신청하세요.
```


## 5. 대본 쓸 때 지킨 원칙

- **"무조건", "100%", "최대 O억" 같은 확정 표현을 쓰지 않았습니다.** F6은 오히려 "무조건 되나요? 아닙니다"라고 먼저 말합니다. 홈페이지 기획안의 상담 원칙과 광고 규제 검토(10장)를 따른 것입니다.
- **"대출해 드립니다", "받아 드립니다"처럼 하랑솔루션이 직접 자금을 주는 것처럼 들리는 말도 쓰지 않았습니다.** 진단하고 순서를 정한다는 표현만 씁니다.
- F5의 상담 예시는 화면에 "이해를 돕기 위한 예시"라고 표시되어 있습니다. 실제 사례로 바꾸려면 식별 정보를 빼고 써야 합니다.
- 대본 줄과 시간을 바꾸려면 `cues-short.js`, `cues-fund.js`의 `vo` 항목을 고치고 `python3 tools/vo_check.py cues-short.js cues-fund.js`로 자리에 맞는지 확인합니다.
